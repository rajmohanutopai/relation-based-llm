# Theory of Information, Cognition, and Abstraction

Source: `Chapter_12_Mind_Your_Reality.pdf`

Status: canonical project note for the in-scope theory.

Implementation direction: see `docs/developmental-relation-graph.md` for the
first concrete structure for a relation-first SLM training scaffold.

## Scope

This note captures the theory of information, cognition, learning, decision-making,
and abstraction from Chapter 12.

It intentionally excludes the later extensions into self/group identity,
metaphysics, Brahman/Maya, ritual memory, and physics. Those may be discussed
elsewhere, but they are outside the scope of this project note.

The "domino" language in the chapter is a simplified explanatory model for a
general neural-network-like process. It is meant to make the theory understandable
to non-technical readers. It should not be read as a literal claim that mind works
through physical dominoes.

## Core Claim

The mind is a dynamic relational network.

Information is not stored as isolated facts. Information exists only through
relations. Meaning arises from the pattern of relations between sensory traces,
actions, emotions, contexts, words, memories, and abstractions.

Thought is not the stored relation itself. Thought is the active process of
activation moving through stored relations.

In simplified terms:

- A domino is a neural unit, feature, trace, or pattern component.
- A connection is a learned relation between units or patterns.
- Toppling is activation.
- Swaying is sub-threshold activation or priming.
- Connection strength is the learned weight of association.
- A threshold is the activation level required for a downstream pattern or action
  to fire.
- A row or path of dominoes is an activation pathway.
- Splitting is one activation spreading to multiple associated patterns.
- Merging is multiple activations combining, competing, or being compared.
- Context is the current field of partially active associations.
- A concept is a stable abstraction built from many lower-level relations.

## Information Is Relation

The foundational claim is that there is no meaning in a single isolated unit.
A unit has meaning only because of what it is connected to.

For example, a "ball" is not represented as a self-contained object inside the
mind. It is a fuzzy abstraction formed by relations among:

- roundness
- bounciness
- hand-feel
- expected movement
- visual shape
- the sound or word "ball"
- possible actions, such as throwing, catching, bouncing
- expected consequences, such as breaking a window

The mind does not understand "ball" as a perfect definition. It understands a
cluster of relations that are good enough for recognition, prediction, and action.

This makes all information approximate. The mind works with fuzzy relational
patterns, not exact symbolic definitions.

## Sensation, Action, and Thought

Sensations can be modeled as activation moving inward from sensory input.
Actions can be modeled as activation moving outward toward behavior.

A simple reflex is a short path from sensation to action. For example:

1. Heat/pain is sensed.
2. The relevant activation path fires.
3. A withdrawal action fires.
4. The hand moves away.

Non-reflexive thought uses the same basic mechanism, but it is recurrent rather
than linear. Activation cycles through internal associations before an action is
selected.

In this model, rational thought is not a separate substance or faculty. It is many
rounds of activation, association, comparison, inhibition, reactivation, and
decision pressure operating over learned relations.

## Computation by Merging and Splitting

The chapter uses merging and splitting rows of dominoes to explain computation.
In neural-network terms, this corresponds to activation spreading, summation,
competition, inhibition, and thresholding.

When one activation path splits, the same sensation or thought triggers multiple
associated patterns.

When multiple paths merge, the result depends on their combined strength and
relation:

- If they support each other, they may sum and push a downstream pattern over
  threshold.
- If they oppose each other, they may cancel, inhibit, or create comparison.
- If neither is strong enough alone, the combined context may still trigger an
  action or thought.

Example:

- Hearing a rattle may not be enough to pull the foot back.
- Seeing movement may not be enough either.
- Hearing a rattle plus seeing movement may jointly cross threshold.

This is how a simple relational network can produce behavior that looks like
calculation or judgment without requiring a separate inner calculator.

## Context as Priming

Context is one of the central mechanisms in the theory.

Context is the set of currently active or partially active associations. In the
domino metaphor, these are dominoes already swaying. In neural terms, this is
priming or residual activation.

Context changes interpretation.

Example: the word "lift"

- If the current context is physical instruction, "lift" may activate raising the
  hand or lifting an object.
- If the current context is a friend stopping a car, "lift" may activate the idea
  of a car ride.

The external word is the same, but the interpretation changes because different
associations are already close to threshold.

Context also decays over time. As activation fades, old context loses influence.
This helps explain why temporal closeness matters for perceived cause and effect.

## Learning

The mind builds its internal model by modifying connection strengths.

The core learning rule is:

- Patterns that activate together become more strongly connected.
- Patterns that fail to cohere, or are repeatedly contradicted by experience,
  become weaker or less central.

When a child sees a bouncing round object while hearing the word "ball," several
patterns activate together:

- roundness
- bounciness
- visual object boundary
- the spoken sound "ball"
- actions involving the object

Because these patterns co-activate, the connections among them strengthen. Over
time, the mind forms the abstraction "ball."

The abstraction is not created by explicit definition. It emerges from repeated
relational co-activation.

## Essential and Incidental Properties

The theory explains abstraction by distinguishing essential from incidental
relations through repeated experience.

Example: ball and color

A ball may appear in many colors. Since no single color is consistently tied to
ball, the connection between ball and any one color remains weak. However, the
general relation between ball and the property "can have color" becomes stronger.

This produces a higher-level abstraction:

- not "ball is red"
- not "ball is blue"
- but "ball can be of some color"

This allows the mind to generalize beyond direct experience. A person may have
seen only three colors of balls, but still understand that a ball could have other
colors.

Example: leaf and green

A leaf is often green, so the leaf-green relation becomes strong. But the general
color relation still exists in the background. This creates a weak skeptical
possibility: a leaf need not always be green.

This is important because skepticism does not require a separate logical module.
It can arise naturally from weaker but still present alternative relations.

## Abstraction

An abstraction is a stable higher-level pattern formed from repeated relational
structure.

The mind does not merely store examples. It extracts common relational patterns
across examples.

Abstractions can be built from:

- sensory features
- actions
- consequences
- emotions
- language
- contexts
- other abstractions

This creates a hierarchy of meaning. Lower-level patterns combine into object
concepts. Object concepts combine into event concepts. Event concepts combine
into causal, social, moral, and theoretical abstractions.

The same mechanism can explain:

- object recognition
- pattern matching
- generalization
- analogy
- categorization
- expectation
- skepticism
- language meaning
- decision-making strategies

## Thought as Cyclic Refinement

The chapter rejects a purely linear model of thought.

Reflexes may be close to linear. Most thought is cyclic.

The past shapes the present because learned relations determine what activates.
The present shapes the future because current activations change context,
strengthen or weaken associations, and bias the next cycle.

In difficult thought, activation may cycle through many internal patterns:

1. A question or problem activates relevant associations.
2. Those associations activate related memories, concepts, and emotions.
3. Some paths support each other and grow stronger.
4. Some paths oppose or inhibit each other.
5. Context shifts after each cycle.
6. New associations become reachable.
7. A decision, insight, or action eventually crosses threshold.

This gives a non-mystical account of thinking, judging, deliberating, and
understanding.

## Decision-Making

The chapter treats decision-making as a search for a path that reduces pain,
discomfort, conflict, or unresolved pressure below a threshold.

Pain here should be read broadly. It includes physical pain, but also social,
emotional, moral, predictive, and cognitive discomfort.

Simple example: hot pan

1. Touching the pan produces pain.
2. Multiple possible actions are tried or activated.
3. Pulling the hand back reduces pain.
4. The pain pattern and withdrawal action co-activate.
5. The connection strengthens.
6. Next time, the response is faster.

This explains how a useful decision can arise before the connection has already
been learned.

Complex decisions work similarly, but with many competing pressures.

Example: someone asks you to lift your hand

Possible pressures include:

- obedience to authority
- social respect
- effort
- embarrassment
- moral discomfort
- desire to cooperate
- desire to refuse

The mind does not necessarily find a perfect answer. It searches until it finds a
good-enough path where the unresolved pressure is low enough.

This makes decision-making a compromise process rather than a pure optimization
process.

## Meta-Decision Abstractions

The chapter proposes that the mind learns abstractions not only about objects and
events, but also about decision-making itself.

Repeated problem-solving can create higher-level strategies.

Examples:

- Negation: if one action increases pain, try the opposite.
- Variation: if a direct path fails, change the framing or try a different path.
- Randomization: bring unrelated material into context to trigger new relations.
- Sleep or delay: allow context to settle and later reactivate differently.

These are "meta decisioning abstractions": learned patterns that influence how
future decisions are searched.

This helps explain how the mind avoids examining every possible option from
scratch. It learns reusable search strategies from previous decisions.

## Innovation and Insight

Innovation is explained as new or previously weak relations becoming active.

This can happen in at least two ways:

1. Context brings unrelated patterns together. If they activate together, a new
   relation forms.
2. Deep thought activates distant associations. A weak hidden relation becomes
   strong enough to affect the current problem.

Original thought is therefore not creation from nothing. It is the discovery,
formation, or strengthening of a relation that was not previously available to
conscious thought.

## Happiness, Beauty, and Grief

Although the main decision model emphasizes pain, the chapter also suggests a
positive counterpart: happiness can arise from useful or meaningful new
connections.

For this project, happiness should be modeled through two mechanisms:

1. Existing positive relation activation.
   A current cue activates already learned happiness-linked relation clusters.
   For example, a familiar caregiver's soft voice activates prior comfort,
   safety, feeding, touch, and attention relations.

2. New useful relation formation.
   A new relation is created or strengthened. If many useful relations form
   together, happiness increases. This covers discovery, play, insight,
   elegance, and learning.

Learning something elegant may feel good because it links many existing patterns
under a deeper abstraction.

There is also an important saturation rule:

```text
if a happiness-linked relation is already strong,
then repeating the same activation gives less additional happiness.
```

So happiness is not just total positive activation. It is strongly affected by
marginal connection gain. The first useful relation may feel exciting; the
hundredth repetition may only maintain comfort or expectation. To increase
happiness again, the system seeks novelty, intensity, a higher-level pattern, or
a wider social reference group.

This helps connect Chapter 09 to the mind theory. Society trains concepts such
as money, respect, success, ethics, belonging, and achievement as paths to
happiness. But these paths can saturate. Respect from one group can stop being
enough once that relation is familiar, so the person seeks respect from a more
selective group, then a still higher group. The same mechanism can explain
healthy growth and unhealthy escalation.

Hard drug use is a failure mode of the same architecture: direct positive
activation occurs without useful relation formation. It exploits the happiness
signal while bypassing the relational growth that normally justifies the signal.
The training objective should therefore favor long-horizon relational growth,
not raw positive activation alone.

This can help explain why people respond positively to:

- elegance
- efficiency
- originality
- explanatory power
- beauty
- opulence
- coherent theory

Each produces a rich pattern of connection, compression, or expansion.

Grief is described as the inverse. Losing someone close is painful because many
relations tied to that person are broken, blocked, or can no longer be activated
in the expected way. The closer the person, the denser the lost network, and the
greater the pain.

Sadness should therefore be modeled as connection loss or blocked expected
positive activation. In infancy this may be caregiver absence or delayed comfort.
In adulthood it can become grief when a dense person-relation network can no
longer activate normally.

## Language

Words are not meanings by themselves. A word is an activation handle into a
network of relations.

Hearing a word activates:

- sound patterns
- prior uses
- sensory associations
- emotional associations
- action possibilities
- social context
- current context

The meaning selected in a given moment depends on which related patterns are
already primed and which cross threshold.

This explains ambiguity without needing a dictionary-like internal structure.

## Formal Restatement

The theory can be restated more formally as follows.

Let the mind be a weighted recurrent network of units or patterns.

- Each unit has an activation level.
- Connections between units have learned strengths.
- Inputs raise activation in sensory-linked units.
- Activation spreads through weighted connections.
- Multiple activations may sum, inhibit, or compete.
- Patterns fire when activation crosses threshold.
- Recent activation persists as context.
- Co-activated patterns strengthen their connections.
- Repeated structures form higher-order abstractions.
- Decisions occur when an action pattern resolves pressure below a threshold.

In this view, cognition is not symbolic manipulation first. It is relational
activation first. Symbolic thought is a later abstraction built on the same base.

## Important Boundaries

This theory should not be presented as:

- literal domino mechanics
- a complete neuroscience model
- proof of metaphysical claims
- a physics theory
- a claim that all cognition is conscious
- a claim that all decisions are rational

It should be presented as:

- a relational model of information
- a neural-network-inspired account of meaning
- a dynamic account of cognition
- an abstraction-first account of concepts
- a context-sensitive account of interpretation
- a threshold-based account of decision-making
- a learning-based account of generalization

## Open Questions for Future Work

The following questions remain useful for later formalization:

- What exactly is a "unit" in the technical version: neuron, feature, pattern,
  trace, concept node, or all of these at different levels?
- How should inhibition be modeled?
- Are opposing dominoes best represented as negative weights, competing pathways,
  phase mismatch, or threshold failure?
- How does attention select which active patterns receive more processing?
- How does the system prevent combinatorial explosion during thought?
- How are pain, discomfort, reward, and happiness represented technically?
- How does language attach to pre-linguistic abstractions?
- How do stable abstractions become available for conscious manipulation?
- How does the theory distinguish weak association from meaningful abstraction?
- What is the relationship between this model and modern neural networks,
  predictive processing, connectionism, reinforcement learning, and embeddings?

## One-Sentence Summary

Mind is a dynamic relational network in which meaning arises from learned
connections, thought is activation moving through those connections, context is
partial activation, abstraction emerges from repeated relational structure, and
decision-making searches for a good-enough path through competing pressures.
